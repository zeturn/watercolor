# WatercolorUI Landing Page

这是 WatercolorUI 组件库的官方落地页，部署在 GitHub Pages 的根路径。

## 功能特性

- 🎨 现代化的设计风格
- 📱 完全响应式布局
- ⚡ 基于 React 和 WatercolorUI 组件构建
- 🔗 快速导航到 React 和 Vue 文档
- 🎯 组件展示和交互演示

## 开发

### 安装依赖

```bash
cd landing-page
npm install
```

### 本地开发

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览构建结果

```bash
npm run preview
```

## 部署

构建完成后，将 `dist` 目录的内容部署到 GitHub Pages 的根路径。

## 技术栈

- React 18
- Vite
- WatercolorUI 组件库
- CSS3 动画和渐变

## 页面结构

1. **导航栏** - 包含 Logo、GitHub 链接和文档导航
2. **Hero 区域** - 主标题和行动按钮
3. **特性展示** - 核心特性介绍
4. **组件展示** - 各种组件的实际演示
5. **快速开始** - React 和 Vue 版本选择
6. **页脚** - 相关链接和版权信息

## 自定义

可以通过修改以下文件来自定义页面：

- `src/App.jsx` - 主要内容和布局
- `src/App.css` - 样式和动画
- `src/index.css` - 全局样式
- `index.html` - HTML 模板和 meta 信息
