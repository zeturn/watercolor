# @zeturn/watercolor-icons-heroicons-vue

Heroicons icon resolver for Watercolor UI (Vue).

## Install

```bash
npm install @zeturn/watercolor-icons-heroicons-vue
```

## Usage

```ts
import { getIcon } from '@zeturn/watercolor-icons-heroicons-vue'

const Icon = getIcon('academic-cap')
```
