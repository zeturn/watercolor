# @zeturn/watercolor-icons-phosphor-vue

Phosphor icon resolver for Watercolor UI (Vue).

## Install

```bash
npm install @zeturn/watercolor-icons-phosphor-vue
```

## Usage

```ts
import { getIcon } from '@zeturn/watercolor-icons-phosphor-vue'

const Icon = getIcon('airplane-tilt')
```
