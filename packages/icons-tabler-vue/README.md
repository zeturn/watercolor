# @zeturn/watercolor-icons-tabler-vue

Tabler icon resolver for Watercolor UI (Vue).

## Install

```bash
npm install @zeturn/watercolor-icons-tabler-vue
```

## Usage

```ts
import { getIcon } from '@zeturn/watercolor-icons-tabler-vue'

const Icon = getIcon('alert-circle')
```
