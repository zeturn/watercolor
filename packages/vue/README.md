# @zeturn/watercolor-vue

Watercolor UI components for Vue 3.5+. Built with TypeScript.

## Install

```bash
npm install @zeturn/watercolor-vue
```

## Usage

```ts
import '@zeturn/watercolor-vue/style.css'
import { Button } from '@zeturn/watercolor-vue'
```

Icon packs are optional. Install only the Watercolor wrapper you use, for
example `npm install @zeturn/watercolor-icons-lucide-vue`.
