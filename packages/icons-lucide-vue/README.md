# @zeturn/watercolor-icons-lucide-vue

Lucide icon resolver for Watercolor UI (Vue).

## Install

```bash
npm install @zeturn/watercolor-icons-lucide-vue
```

## Usage

```ts
import { getIcon } from '@zeturn/watercolor-icons-lucide-vue'

const Icon = getIcon('log-in')
```
