# @zeturn/watercolor-icons-phosphor-react

Phosphor icon resolver for Watercolor UI (React).

## Install

```bash
npm install @zeturn/watercolor-icons-phosphor-react
```

## Usage

```ts
import { getIcon } from '@zeturn/watercolor-icons-phosphor-react'

const Icon = getIcon('airplane-tilt')
```
