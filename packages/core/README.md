# @zeturn/watercolor-core

Shared core utilities for Watercolor UI components (framework-agnostic).

## Install

```bash
npm install @zeturn/watercolor-core
```

## Usage

```ts
import { ButtonUtils } from '@zeturn/watercolor-core'
```
