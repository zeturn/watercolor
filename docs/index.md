# Watercolor UI 2.0

Watercolor provides React, Vue, Svelte and Angular components, plus Next.js support.
Solid and Astro are available as private source workspaces in this repository.

React and Next.js icons now use explicit component imports. Individual component
and icon entrypoints keep unused icon catalogs outside the build graph.
