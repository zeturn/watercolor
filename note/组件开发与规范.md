## 2. 组件开发流程与最佳实践

### 2.1 命名与目录结构
- 组件名采用 PascalCase，如：Button、TextField。
- 每个组件单独文件夹，包含 Vue/React 实现、样式、文档等：
  ```
  src/components/Button/
    ├── Button.vue
    ├── Button.jsx
    ├── style.css
    ├── README.md
    └── ...
  ```
- 组件统一通过 `entry-vue.ts`、`entry-react.ts` 管理导出。

### 2.2 API 兼容
- 优先对齐 Material-UI，便于迁移。
- 所有组件需支持主题系统。
- 遵循 a11y 标准，支持键盘导航、ARIA 属性。
- 响应式设计，适配移动端和桌面端。
- TypeScript 全面覆盖类型。

### 2.3 文档与 Storybook
- 每个组件需有完整文档和 Storybook 示例。
- 文档需包含用法、Props、事件、样式、注意事项等。

### 2.4 单元测试
- 核心逻辑需有测试覆盖。

## 3. 组件文档模板

```md
# 组件名（英文）
## Introduction
简要介绍组件功能和用途。

## Installation
如何安装和集成组件。
```bash
npm install watercolor-ui
```

## Usage
代码示例：
```jsx
import { Button } from 'watercolor-ui';

function App() {
  return <Button variant="contained">按钮</Button>;
}
```

## Props
| Prop Name | Type | Default | Description |
| --------- | ---- | ------- | ----------- |
| prop1     | Type | Default | 说明        |

## Events
| Event Name | Description |
| ---------- | ----------- |
| event1     | 说明        |

## Styling
如何自定义样式。

## Notes
使用注意事项。

## Contribution
如何贡献代码。

## License
MIT

## Reviewer
Reviewed by: [@zeturn](https://github.com/zeturn)
mm-dd-yyyy
```

## 4. 组件文档编写规范
- Props、Events、Styling、Notes、Contribution、License 等部分需详细、准确。
- 示例代码需可直接运行。
- 表格对齐，描述清晰。

## 5. 贡献与协作流程
- 遵循本规范进行开发和文档编写。
- 所有新组件需先提 issue 讨论。
- 合并前需通过代码审查和自动化测试。
- 详细贡献流程见项目 CONTRIBUTING.md。
