## 📝 快速参考

### 安装命令
```bash
npm install watercolor-ui
```

### 基础使用
```javascript
// Vue 3
import { ButtonVue, InputVue, CardVue } from 'watercolor-ui'

// React 18+
import { ButtonReact, InputReact, CardReact } from 'watercolor-ui'

```

### 样式导入
```javascript
import 'watercolor-ui/dist/style.css'
```

### 主题切换
```javascript
import { applyTheme } from 'watercolor-ui'

// 切换到不同主题
applyTheme('ocean')    // 海洋蓝
applyTheme('forest')   // 森林绿
applyTheme('sunset')   // 夕阳橙
applyTheme('violet')   // 紫罗兰
applyTheme('rose')     // 玫瑰粉
```
