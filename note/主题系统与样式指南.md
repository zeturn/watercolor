# 主题与样式指南

> 本文档适用于 Watercolor UI 组件库的主题系统、样式自定义、字体管理等相关开发与维护，帮助团队成员高效实现多主题、品牌定制、响应式与无障碍设计。

---

## 1. 文档说明

Watercolor UI 采用文件驱动的主题系统，支持多主题切换、深色模式、品牌色、字体、圆角等扩展配置。所有主题配置集中在 `theme.config.json`，并支持运行时动态切换。

---

## 2. 主题系统架构与文件驱动

- 主题配置文件：`theme.config.json`，集中管理主/副色、状态色、字体、圆角等。
- 支持多主题切换、深色模式、品牌主题、运行时动态切换。
- 主题变量通过 CSS 变量注入，支持响应式和 Tree-shaking。
- 兼容 Material-UI 主题配置，便于迁移。

### 2.1 主题配置文件结构示例
```json
{
  "primary": { "50": "#eff6ff", "100": "#dbeafe", ... },
  "secondary": { "50": "#f3f4ff", ... },
  "fonts": {
    "chinese": "Noto Sans SC",
    "english": "Inter",
    "fallback": "-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif"
  },
  "radius": { "sm": "0.125rem", "md": "0.25rem", ... }
}
```

### 2.2 主题切换与加载
```js
import { loadThemeConfig } from 'watercolor-ui/theme'
// 加载默认主题
await loadThemeConfig()
// 加载自定义主题
await loadThemeConfig('/themes/brand.json')
```
- 支持多环境（如 dev/prod）主题文件。
- 支持运行时切换（如夜间模式、品牌主题）。

### 2.3 主题迁移与升级
- 旧版内置主题（如 forest、sunset）已废弃，需迁移到文件驱动。
- 步骤：将原主题变量写入 `theme.config.json`，通过 `loadThemeConfig` 加载。

---

## 3. 主题色彩体系

- 主色（primary）、副色（secondary）为必选，支持 10 个色阶。
- 成功、警告、错误、信息、中性色可选，建议补全。
- 支持扩展色板（如 purple、teal、indigo）。

### 3.1 主题色配置示例
```json
{
  "primary": { "50": "#eff6ff", "100": "#dbeafe", ... },
  "secondary": { "50": "#f3f4ff", ... },
  "success": { ... },
  "warning": { ... },
  "error": { ... },
  "info": { ... },
  "neutral": { ... }
}
```

### 3.2 主题切换 API
```js
import { applyTheme } from '@/utils/theme'
applyTheme('ocean') // 切换到海洋蓝主题
```

## 4. 字体主题与管理

Watercolor UI 支持中英文分离、响应式、可定制的字体主题。

### 4.1 字体主题配置
```json
{
  "fonts": {
    "chinese": "PingFang SC",
    "english": "Inter",
    "fallback": "system-ui, sans-serif"
  }
}
```

### 4.2 字体主题切换
```js
import { applyFontTheme, setFonts } from 'watercolor-ui/theme'
applyFontTheme('modern')
setFonts({ chinese: 'PingFang SC', english: 'Inter', fallback: 'sans-serif' })
```

### 4.3 预设字体主题
| 主题名称 | 中文字体 | 英文字体 | 适用场景 |
|---------|---------|---------|---------|
| system | system-ui | system-ui | 系统原生外观 |
| chinese | PingFang SC | SF Pro Display | 中文内容为主的应用 |
| modern | Noto Sans SC | Inter | 现代化界面设计 |
| elegant | Source Han Sans | Poppins | 优雅精致的设计 |
| readable | IBM Plex Sans SC | IBM Plex Sans | 阅读性要求高的应用 |
| apple | PingFang SC | SF Pro Display | 苹果生态系统风格 |
| google | Noto Sans SC | Roboto | Google Material Design风格 |

### 4.4 字体 CSS 变量
```css
:root {
  --wc-font-family: ...;
  --wc-font-chinese: ...;
  --wc-font-english: ...;
}
```

## 5. 样式覆盖与自定义

- 支持全局和局部样式覆盖。
- 推荐通过 CSS 变量自定义主题色、字体、圆角等。
- 组件样式可通过 className、style 覆盖。
- 支持暗色模式、响应式断点。

### 5.1 自定义样式示例
```css
.my-custom-btn {
  background: var(--wc-primary-500);
  font-family: var(--wc-font-family);
  border-radius: var(--wc-radius-md);
}
```

---

## 6. 主题/字体API用法

```js
import { loadThemeConfig, applyTheme, applyFontTheme, setFonts } from 'watercolor-ui/theme'
// 加载主题
await loadThemeConfig()
// 切换主题
applyTheme('ocean')
// 应用字体主题
applyFontTheme('modern')
// 自定义字体
setFonts({ chinese: 'PingFang SC', english: 'Inter', fallback: 'sans-serif' })
```

## 7. 最佳实践与常见问题

- 主题配置文件建议纳入版本控制，团队统一。
- 多环境/多品牌建议分文件管理，运行时切换。
- 字体主题建议根据终端类型自动适配。
- 组件开发需兼容主题变量，避免硬编码颜色。
- Storybook 建议展示多主题切换效果。

### 常见问题
- 主题/字体不生效：检查 theme.config.json 路径、格式、变量名。
- 样式冲突：提升选择器优先级或使用 `!important`。
- 响应式异常：检查断点配置和媒体查询。
